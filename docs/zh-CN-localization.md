# 简体中文本地化（开发中）

此 Fork 在保留原版功能的基础上逐步增加简体中文界面。当前**不是完整汉化版本**，请勿将其视作可发布的稳定构建。

## 当前已实现

- `app/src/lib/i18n.ts`：简体中文文案表、英文回退、根据系统语言选择初始语言，以及通过 `localStorage` 保存手动选择的语言。
- 设置 → 外观 → **界面语言**：可以选择 **English** 或 **简体中文**。切换时重新载入渲染进程，请先保存其他设置。
- 欢迎页、首次 Git 身份配置、登录对话框中的部分文案。
- 设置页标签、外观选项中的部分文案。

## 尚未完成

仓库列表、提交与差异、分支操作、原生 macOS 菜单、错误提示、辅助功能文案及其他界面尚未系统性翻译。语言资源仅用于已经接入 `t()` 的字符串，不会自动翻译所有文字。

## 开发与验证

遵循上游 `desktop/desktop` 的开发指引安装依赖和执行 lint、类型检查及测试。当前提交仅通过仓库 API 写入，**尚未在 macOS 本地编译或测试**。完成自动化测试和人工界面验收前不要发布正式安装包。

上游项目： https://github.com/desktop/desktop
